Recovery Architecture

01

Fail-Forward Decompressor

Per-file ZIP isolation. Each entry extracted independently with CRC bypass. LZMA chunks zero-padded on failure. Every file gets its chance.

02

Zombie LZMA Decoder

8-offset byte-slide resync with TaintMap bit-vector. Chunk-level retry across corrupted LZMA2 streams. Marks tainted output regions for quality metadata.

03

AhoCorasick Magic Carver

29 file signatures scanned in single pass. JPEG/PNG/PDF/MP4/ZIP/EXE/ELF/RIFF/TIFF/FLAC/WAV/AVI/WASM/TAR — with file-end refinement and deduplication.

04

Decompression Pipelines

GZIP, BZIP2, XZ transparent decompression. TAR archive extraction with nested file recovery. Shannon entropy gating rejects noise blocks.

05

Integrity Reporter

SHA-256 per file. Content-based deduplication for raw carves. Type breakdown, downloadable recovery ZIP, and full audit trail.
